# Project Title
School Lost & Found System

## Project Description
This is a simple Python program that helps students and school staff report, search, and manage lost and found items. Users can report items they lost or found, search for specific items, view lists of lost and found items, and claim items that belong to them.

## Features
- Report a lost item
- Report a found item
- Search for an item
- View all lost items
- View all found items
- Claim a found item
- View claimed items
- Exit the program
- Handles multiple lost and found items

## How to Run the Program
1. Make sure you have Python installed.
2. Download the file `lost_found_system.py`.
3. Open the file in a Python editor.
4. Run the program by pressing F5 or clicking "Run".
5. Follow the on-screen instructions and choose an option from the menu.
