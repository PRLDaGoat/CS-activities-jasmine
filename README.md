Project Title
School Lost & Found System

Project Description
This is a simple Python program that helps students and school staff report, search, and manage lost and found items. Users can report items they lost or found, search for specific items, view lists of lost and found items, and claim items that belong to them.

Features
-Report a lost item
-Report a found item
-View Lost Items
-View Found Items
-Exit the program

How to Run the Program
Make sure you have Python installed.
Download the file lost_found_system.py.
Open the file in a Python editor.
Run the program by pressing F5 or clicking "Run".
Follow the on-screen instructions and choose an option from the menu.
