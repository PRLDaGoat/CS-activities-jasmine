# CHANGELOG

This file lists all the updates made to our School Lost & Found System project.

---

## Version v1.0.0 – August 28, 2026
- First idea of the project.
- Created the School Lost & Found System.
- Added a menu for the system.
- User can:
  - Report a lost item
  - Report a found item
  - View lost items
  - View found items
  - Exit the program

---

## Version v1.1.0 – August 25, 2026

- Added the date lost/found to the report.
- Improved the display of lost and found item information.
- Improved the menu and user interface.

## Version v1.2.0 – August 28, 2026
