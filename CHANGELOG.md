**Project:** Lost and Found Tracking and Catalog System  
**Versioning Format:** `vX.Y.Z`

## [v1.0.0] - 08-26-2026
### Initial Release

The first working version of the Lost and Found Tracking and Catalog System was created.

### Added
- Added the main menu with five options: Report Lost Item, Report Found Item, View Lost Items, View Found Items, and Exit.
- Added the **Report Lost Item** form for entering the item name, description, last known location, and date lost.
- Added the **Report Found Item** form for recording information about found items.

---

## [v1.0.1] - 08-27-2026
### Update: Item Viewing and Record Organization

### Added
- Added **View Lost Items** to display all lost-item records entered into the system.
- Added **View Found Items** to display all found-item records entered into the system.

### Changed
- Organized lost and found records into separate lists to make the information easier to view and manage.

---

## [v1.0.2] - 08-28-2026
### Update: User Input and Program Navigation

### Changed
- Improved the report forms to collect both the date the item was lost/found and the date the report was submitted.
- Improved the menu flow so users can return to the main menu after completing an action.
- Improved the exit option so users can safely finish the program.

### Notes
- The system stores reported items during program runtime.
- The sample data demonstrates a lost black wallet with its description, last known location, and relevant dates.
